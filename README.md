# Проект по БД

## Описание проекта
В рамках проекта были получены данные о компаниях и вакансиях с сайта hh.ru, 
спроектированы таблицы в БД PostgreSQL. Полученные данные загружены в созданные таблицы.

## Основные шаги проекта
* Были получены данные о работодателях и их вакансиях с сайта hh.ru. Для этого 
использовался публичный API hh.ru и библиотека requests;
* Выбрано 10 компаний, от которых можно получать данные о вакансиях по API;
* Спроектированы таблицы в БД PostgreSQL для хранения полученных данных о работодателях 
и их вакансиях. Для работы с БД используется библиотека psycopg2;
* Реализован код, который заполняет созданные в БД PostgreSQL таблицы данными о работодателях 
и их вакансиях;
* Создан класс DBManager для работы с данными в БД.

## Требования к окружению:

```
Python 3.13+
```

## Установка:
* Клонируйте репозиторий:
```
git clone https://github.com/Svetlana062/Python_Project_3.git
```
* Установите зависимости:
```
pip install -r requirements.txt
```
* В случае отсутствия менеджера проектов _poetry_, выполните установку пакетов:
```
poetry install
```
* Войдите в виртуальное окружение:
```
poetry shell
```

## Тестирование
Набор тестов находится в пакете tests.
Чтобы начать тестирование, необходимо, через терминал, установить pytest:
```
poetry add --group dev pytest
```
### Покрытие кода тестами:

Используется инструмент pytest-cov для измерения покрытия кода тестами.
Текущий процент покрытия составляет 96%.

## Структура проекта
* src/db_manager.py - модуль, отвечающий за подключение к БД;
* src/file_manager.py - модуль, содержащий класс для работы с файлами;
* src/hhru_api.py - модуль, содержащий класс для взаимодействия с API hh.ru;
* src/user_interaction.py - модуль, для взаимодействия с пользователем;
* src/vacancy_manager.py - модуль, содержащий класс для работы с вакансиями;
* data/employer_ids.json - файл, содержащий id компаний;
* data/vacancies.json - файл, для сохранения информации.
